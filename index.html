    実際の字幕

    同じ音声でも、辞書があれば用語が字幕に出ます

    模擬 LT の同じ音声を、AmiVoice API の会話_汎用エンジンでライブ認識した字幕です。下線の語は、スライドから作った辞書で正しく出た語です。

    合成音声で作った模擬 LT 3 本（用語 75 か所）の結果です。辞書を渡しても、字幕が確定するまでの時間はほとんど変わりません。

    スライドから辞書

    スライドを渡すと、用語と読みの辞書ができます

    PDF を渡すと、製品名や略語、英語の API 名を Claude が抜き出し、AmiVoice API が手がかりにするひらがなの読みを付けます。表で直して保存すれば、配信中でも数秒で新しい辞書に切り替わります。

    • 読みが空の語や、かなに直せない読みは赤で知らせます
    • 同じ読みの語が 2 つあると字幕がどちらに転ぶか分からないので、組を示します

    アーカイブと振り返り

    登壇のあとに、字幕を作り直して振り返りをまとめます

    録音した登壇は、終わったあとに AmiVoice API の非同期 API で認識し直してアーカイブ字幕にします。話す速さ、フィラー、声の調子から推定した感情の起伏を時間に沿って並べ、次の登壇に向けた辞書の候補も出します。

    • アーカイブ字幕は WebVTT と Markdown で書き出せます
    • 録音は振り返りの画面からいつでも削除できます

    よくある質問

    ほかに気になることは、GitHub の Issue で聞いてください。

    参加者には何が必要ですか？

    ブラウザだけです。QR コードかリンクを開けば、アカウントもアプリもなしで字幕を見られます。

    どのくらい正確ですか？

    合成音声で作った模擬 LT 3 本では、スライドから作った辞書で文字の誤り率が 14.1% から 3.1% に下がり、用語 75 か所のうち 73 か所が正しく出ました。実際の LT の録音でも、登壇者の記事から作った辞書で固有の製品名が正しく出るようになりました。一方で、同じ読みの語が辞書に 2 つあると、辞書なしでは正しかった語が別の表記に変わることもあります。

    辞書はどうやって作られますか？

    スライドの PDF か資料のテキストを Claude に渡し、音声認識で崩れやすい語と、そのひらがなの読みを抜き出させます。AmiVoice API には「表記と読み」の組（profileWords）として渡し、ハイブリッドエンジンが読みを手がかりに表記を選びます。

    音声や字幕はどこに残りますか？

    AmiVoice API には、AmiVoice 側にログを残さない設定で送っています。「録音してアーカイブを作る」をオンにした登壇だけ、音声を Cloudflare R2 に保存します。録音は振り返りの画面から削除できます。参加者の画面には「録音中」と出るので、勉強会の冒頭でも録音することを伝えてください。

    料金はかかりますか？

    参加者は無料です。音声認識には AmiVoice API を使うので、自分で動かす場合は AmiVoice の利用料がかかります。月に使う時間の上限を決めておくと、上限に達したあとの配信は始められなくなります。

    自分の勉強会用に動かせますか？

    MIT ライセンスで公開しています。Cloudflare Workers と Durable Objects で動き、AmiVoice API と Anthropic API のキーがあればデプロイできます。手順は README にあります。
